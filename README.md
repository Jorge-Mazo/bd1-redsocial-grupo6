## Descripción del Proyecto
Este proyecto contiene el diseño del Modelo Conceptual Entidad-Relación (MER) para la base de datos de la plataforma institucional "Pascualina", una red social desarrollada para la comunidad estudiantil del Pascual Bravo. El sistema surge ante la necesidad de optimizar la comunicación interna, permitiendo interacciones académicas y casuales que las plataformas formales de la institución no cubren actualmente.

La infraestructura de datos está proyectada para soportar las siguientes funciones esenciales:
* **Perfiles y Logros Académicos:** Administración de perfiles individuales donde los estudiantes exponen sus habilidades, intereses y áreas de estudio, con el fin de fomentar la mentoría entre pares y cursos avanzados.
* **Canales de Interacción:** Registro y control de actualizaciones, recursos educativos, consultas temáticas y noticias del sector tecnológico compartidas por los usuarios.
* **Comunidades de Aprendizaje y Eventos:** Espacios relacionales dirigidos a la creación y gestión de grupos de estudio dedicados, clubes de interés (programación, videojuegos) y la organización logística de talleres o actividades sociales integradoras.

## Entorno Técnico y Documentación
* **Modelado Conceptual:** Diagrama Entidad-Relación desarrollado bajo la metodología y estándares de buenas prácticas de la asignatura.
* **Gestión de Versiones:** Repositorio administrado en equipo mediante Git y GitHub Teams.
* **Estructura de Entregables:** Documentación técnica organizada en carpetas independientes para el informe escrito en PDF y la sustentación audiovisual.
